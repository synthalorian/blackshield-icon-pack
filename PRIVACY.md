# Privacy Policy — Blackshield Icons / Blackshield Red

**Effective date:** September 10, 2026

## The short version

Blackshield Icons collects **no data whatsoever**. It is a static icon pack:
it contains icon artwork and a mapping table that launchers read locally on
your device. That's all it does.

## What the app accesses

- **No network access** — the app does not request the internet permission and
  never connects to anything.
- **No personal data** — no accounts, no analytics, no telemetry, no crash
  reporting, no advertising IDs.
- **No device data** — no location, contacts, storage, microphone, camera, or
  any other sensitive permission.

## Icon requests / contact

If you email the developer (or open a GitHub issue) to request an icon, that
message and your email address are handled by your email provider / GitHub
under their own privacy policies. Nothing is transmitted by the app itself.

## Changes

If this ever changes, this document changes first, in this repository's
public git history.
